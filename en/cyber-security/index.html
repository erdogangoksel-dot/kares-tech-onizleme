Who is it for?

  • Companies with web and mobile apps

    Companies offering web or mobile apps or APIs to customers or staff, who want them tested through an attacker's eyes.

  • Companies running their own servers and network

Cyber Security

Our services

  • Penetration Testing

    See your systems through an attacker's eyes. Controlled attack tests on your web and mobile apps, APIs and infrastructure: source code analysis (SAST) plus dynamic testing on the running system (DAST).

    Deliverable: Prioritised list of findings, risk levels and a remediation roadmap.

  • Web and Application Security

    OWASP Top 10 and beyond: XSS, SQL injection, privilege escalation, session and authentication, file upload / remote code execution (RCE) and business logic flaws. Source code and running application review.

    Deliverable: Vulnerability report, remediation advice and retesting.

  • Server and Network Hardening

    Close open doors without stopping production. Windows/Linux servers, IIS, databases, file servers, virtualisation and network/firewall; MFA/2FA, security headers, least privilege, TLS, endpoint protection. Reversible, step by step, verified.

    Deliverable: Applied hardening, verification report and backups.

  • Database Security

    Protect the heart of your data: permission clean-up (least privilege), audit logging, encryption in transit and account hygiene. SQL Server in particular.

    Deliverable: Permission and audit assessment with a practical remediation plan.

  • Incident Response and Forensics

    If you have been attacked, the first hours are critical. Clean-up checks after a compromise, persistence hunting, tracing and guidance on KVKK breach notification.

    Deliverable: Findings report, clean-up and recovery advice, and notification guidance.

  • Security Assessment and Reporting

    Reports that speak to management and the technical team alike: an executive summary plus technical detail, and verification tests in line with the contract.

    Deliverable: A professional, branded security report.

  • Remediation Support

    We do not stop at finding the flaw; we close it with you. We work alongside your team while findings are fixed: live, under your supervision, verified; on-site or remote.

    Deliverable: Applied fixes with before/after verification.

  • KVKK Security Awareness

    The right step in data security: technical guidance on breach notification and data security processes. This is technical consulting, not legal advice.

    Deliverable: Technical measures and process recommendations.

Cyber Security

Frequently asked questions

Is the service on-site or remote?

Both. We work on-site or remotely as needed; we are based in Izmir and serve all of Türkiye.

Will our systems stop during hardening?

No. Changes are reversible, applied step by step and verified; production keeps running.

Do we get a report?

Yes. You receive a prioritised report with an executive summary and technical detail, and fixes are retested afterwards.

We have been attacked. Can you help?

Yes. We do incident response and clean-up checks: persistence hunting, tracing and technical guidance on KVKK breach notification. Call us directly if it is urgent.

What do you need for a penetration test?

A list of the systems to be tested and your written consent. We agree the scope, test windows and contact person in the first call; testing never goes beyond that scope.

What is the difference between a penetration test and a vulnerability scan?

A vulnerability scan lists known issues with automated tools. A penetration test checks by hand whether they can really be exploited, including business logic flaws, and ranks the real risk.
